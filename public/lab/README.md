# Lab: 3D anatomy test

`/models/anatomy.glb` (used by `/body3d.js` and these lab pages) is the Gymmetry muscle model (github.com/kalibismail/gymmetry-muscle-model), adapted from
Z-Anatomy, the libre 3D atlas of anatomy, by Gauthier Kervyn, based on BodyParts3D (The Database Center for Life
Science, Kousaku Okubo). Licence: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/); the original
BodyParts3D data is CC BY-SA 2.1 Japan. Unmodified here. Only the model is under that licence, not Exodia's code.

Playground (playground.html): only what is new and waits for Marcus. Today: the Aura build at the drop, "In the app now"
next to a smoother version (aura-build.js, both drawn with the app's own /body3d.js), and the Exodia hit animations
(hits.js, also opened from the app's Dev menu with ?play=). body3d-lab.js (body3d.js plus Fable's LAB switches) is no
longer loaded by the playground; it stays for Fable's next round. The older, decided looks live on looks.html
("Legacy anatomies").
