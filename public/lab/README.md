# Lab: 3D anatomy test

`/models/anatomy.glb` (used by `/body3d.js` and these lab pages) is the Gymmetry muscle model (github.com/kalibismail/gymmetry-muscle-model), adapted from
Z-Anatomy, the libre 3D atlas of anatomy, by Gauthier Kervyn, based on BodyParts3D (The Database Center for Life
Science, Kousaku Okubo). Licence: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/); the original
BodyParts3D data is CC BY-SA 2.1 Japan. Unmodified here. Only the model is under that licence, not Exodia's code.

Playground (playground.html): only what is new and waits for Marcus. Its sections are built by fable.js, which draws
"In the app now" with the app's /body3d.js and "Proposed" with body3d-lab.js (body3d.js plus the proposed changes,
each marked LAB and off unless asked for). The older, decided looks live on looks.html ("Legacy anatomies").
